I'm a full-stack developer from **Bangladesh 🇧🇩**, focused on building SaaS products, AI-powered systems, e-commerce platforms, and practical web software.

I run **[SoftWebGrove](https://softwebgrove.com)**, where I work on our own products as well as software for founders and businesses.
